Easy Auth0 migration

  1. Deploy auth2 (Docker, GCP, or AWS)
  2. Point ISSUER_URL to your auth2 instance
  3. Export users from Auth0 (User Import/Export)
  4. Import into auth2 via Management API
  5. Update your app's auth config. Done.
