# auth2 Marketing Website

SEO-optimized landing page for auth2 — Auth0 alternative at half the price.

## Pages

- **index.html** — Main landing: Auth0 alternative, pricing, migration CTA
- **migration.html** — Step-by-step guide to switch from Auth0

## SEO Keywords Targeted

- Auth0 alternative
- Auth0 replacement
- switch from Auth0
- Auth0 migration
- Auth0 competitor
- self-hosted Auth0
- Auth0 pricing alternative
- half the price Auth0

## Deploy

Static HTML/CSS. Deploy to:

- **Vercel:** `vercel website`
- **Netlify:** Drag `website/` folder or connect repo
- **GitHub Pages:** Set `website/` as source, or use `docs/` and copy files

Update canonical URLs and domain in `<link rel="canonical">` when you have a production domain (e.g. `https://auth2.dev`).
